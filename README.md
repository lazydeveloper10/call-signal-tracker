# CALL & SIGNAL TRACKER 📱📡

A lightweight Python CLI utility for parsing, searching, and analyzing personal call logs and mobile network telemetry (RSRP signal strength & cell tower metrics).

> **Note**: Built for personal network log analysis and signal research. Designed for CSV and JSON datasets generated by Android network logging tools.

---

## 🎯 Features

- **Multi-Format Data Loader**: Import call logs and network telemetry from `.csv` or `.json` files.
- **Call Log Inspector**: Filter records by call status (`INCOMING`, `OUTGOING`, `MISSED`) or query by phone number substring.
- **Timestamp Filter**: Slice data records between specific date/time ranges (`YYYY-MM-DD HH:MM:SS`).
- **Signal Quality Metrics & Ratings**:
  - Compute average, min, and max RSRP (Reference Signal Received Power in dBm) with human-readable quality ratings (`Excellent`, `Good`, `Fair`, `Poor`, `Very Poor`).
  - **Dead Zone Detection**: Automatically isolate and warn about poor coverage areas ($\le -110\text{ dBm}$).
  - Identify strongest and weakest connected Cell IDs (`CID`).
  - Analyze Radio Access Technology distribution (`LTE`, `5G NR`, `UMTS`).
  - Rank Top Cell Towers by average signal strength with performance ratings.
- **Report Exporter**: Export filtered or analyzed telemetry into standard CSV reports.


---

## 📊 RSRP Signal Quality Benchmark Guide

| RSRP Range (dBm) | Signal Quality Rating |
| :--- | :--- |
| $\ge -70\text{ dBm}$ | **Excellent** |
| $-70\text{ to }-90\text{ dBm}$ | **Good** |
| $-90\text{ to }-110\text{ dBm}$ | **Fair** |
| $-110\text{ to }-120\text{ dBm}$ | **Poor** |
| $\le -120\text{ dBm}$ | **Very Poor / Dead Zone** |

## 🚀 Quick Start

### 1. Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/lazydeveloper10/call-signal-tracker.git
cd call-signal-tracker
pip install pandas tabulate
```

### 2. Usage
Launch the interactive console:

```bash
python call_signal_tracker.py
```

The script will automatically attempt to load `data/call_data.csv` on startup if present. You can also import custom CSV or JSON logs directly through Option 1 in the main menu.
